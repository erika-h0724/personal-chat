設定

Gemini API

Google AI Studio で無料で作れます。キーはこのブラウザにだけ保存されます。キーを作る

  1. 「キーを作る」を開き、Googleアカウントでログインします。
  2. 「Create API key」を押します。
  3. プロジェクトを聞かれたら、新しく作成を選び、名前を「personal-ai-chat」にします。
  4. 表示されたキー（長い英数字の文字列）をコピーして、上の欄に貼り付けます。

無料のまま使うため、Google側で請求先（Billing）の設定はしないでください。キーは他の人に見せないでください。
